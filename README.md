# 生命游戏 · 元胞实验室

一个打开就能玩的康威生命游戏网页。

**在线地址：** https://wdxxxx3.github.io/game-of-life/

## 有什么

- **模拟器**：基于 HashLife 算法，画布可以无限缩放，能一步步走，也能每帧快进 2^30 代。规则可以填任意 B/S 写法（不支持 B0），可以粘贴和导出 RLE 图样，支持 Golly 的 macrocell 格式。
- **图样库**：245 个图样，分 12 类，每个都有中文名、说明、缩略图和动态预览。
- **图书馆**：10 篇短文，讲生命游戏的历史、计算与哲学，文中的插图都能运行。另附书单和网上资源。

## 快捷键

空格 播放/暂停 · N 单步 · Ctrl+Z 回退 · R 回到起点 · [ ] 调速 · F 适应窗口 · L 图样库 · B 图书馆

## 目录

- `index.html`：整个网页（单文件）
- `patterns.json`：图样库数据
- `src/`：源码。改完后运行 `sh src/build.sh` 重新生成 `index.html`

## 致谢

图样库里约 200 个图样来自 [Golly](https://golly.sourceforge.io/) 4.3 的 Patterns 文件夹（GPL-2.0-or-later），原作者和注释保留在每个图样的“原始注释”里。其余经典小图样由本项目整理，并逐一用引擎验证了周期、速度和寿命。
